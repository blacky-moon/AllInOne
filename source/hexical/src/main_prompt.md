NBT → Data Components (КРИТИЧЕСКИ ВАЖНО!) В 1.21.1 **прямой доступ к NBT предметов удален**. Всё хранится через `DataComponentType`. ```kotlin // БЫЛО: stack.orCreateNbt.putString("key", "value") val nbt = stack.nbt ?: return // СТАЛО: import net.minecraft.core.component.DataComponents import net.minecraft.world.item.component.CustomData val customData = stack.getOrDefault(DataComponents.CUSTOM_DATA, CustomData.EMPTY) val tag = customData.copyTag() tag.putString("key", "value") stack.set(DataComponents.CUSTOM_DATA, CustomData.of(tag)) // Чтение: val tag = stack.get(DataComponents.CUSTOM_DATA)?.copyTag() ?: return ``` **Для кастомных данных используй `DataComponents.CUSTOM_DATA`, НЕ создавай отдельные `DataComponentType` для каждой мелочи!** ### 3. Networking (Fabric API → NeoForge Payload API) ```kotlin // БЫЛО (Fabric): ServerPlayNetworking.send(player, CHANNEL, buf) ClientPlayNetworking.registerGlobalReceiver(CHANNEL) { client, _, buf, _ -> ... } // СТАЛО (NeoForge): // 1. Создай CustomPacketPayload data class MyPayload(val data: Int) : CustomPacketPayload { override fun type() = TYPE companion object { val TYPE = CustomPacketPayload.Type<MyPayload>(HexicalMain.id("my_payload")) val STREAM_CODEC: StreamCodec<RegistryFriendlyByteBuf, MyPayload> = StreamCodec.composite(...) } } // 2. Отправка: PacketDistributor.sendToPlayer(player, MyPayload(data)) PacketDistributor.sendToPlayersTrackingEntity(entity, MyPayload(data)) // 3. Регистрация (через событие): @SubscribeEvent fun onRegisterPayloads(event: RegisterPayloadHandlersEvent) { event.registrar(MOD_ID).playToClient(MyPayload.TYPE, MyPayload.STREAM_CODEC, ::handle) } ``` ### 4. Tooltips ```kotlin // БЫЛО: override fun appendTooltip(stack, world, list, context) ItemTooltipCallback.EVENT.register { ... } // СТАЛО: override fun appendHoverText(stack: ItemStack, context: TooltipContext, list: MutableList<Component>, flag: TooltipFlag) NeoForge.EVENT_BUS.addListener<ItemTooltipEvent> { ... } // Доступ к реестрам: context.registries() ``` ### 5. Iota Serialization (Hex Casting API) ```kotlin // БЫЛО: IotaType.serialize(iota) / IotaType.deserialize(tag, world) IotaType.getDisplay(tag) // СТАЛО: val ops = registryAccess.createSerializationContext(NbtOps.INSTANCE) IotaType.TYPED_CODEC.encodeStart(ops, iota).result().orElse(null) IotaType.TYPED_CODEC.parse(ops, tag).result().orElse(null) iota.display() // метод теперь в самом классе Iota ``` ### 6. Recipes ```kotlin // БЫЛО: override fun matches(inv, world) / getId() / RecipeSerializer с fromJson/toNetwork // СТАЛО: override fun matches(input: RecipeInput, level: Level) // getId() удален — ID теперь в RecipeHolder // Сериализатор требует codec() и streamCodec(), а не fromJson world.recipeManager.getAllRecipesFor(RECIPE_TYPE) // byType стал private ``` ### 7. Particles ```kotlin // БЫЛО: SpriteBillboardParticle, buildGeometry(), velocityX/Y/Z // СТАЛО: TextureSheetParticle, render(VertexConsumer, Camera, float), xd/yd/zd // prevPosX/Y/Z -> xo/yo/zo // getBrightness -> getLightColor ``` ### 8. DeferredHolder (важно в Kotlin!) Всегда вызывай `.get()` для получения объекта: ```kotlin val item = HexicalItems.MY_ITEM.get() // не просто HexicalItems.MY_ITEM ``` Используй `@JvmField` для статического доступа из Java. ## 🔧 ЧАСТЫЕ ОШИБКИ И РЕШЕНИЯ | Ошибка | Причина | Решение | |---|---|---| | `Unresolved reference 'CODEC'` у `ListTag` | `ListTag.CODEC` не существует | Используй `Tag.CODEC.listOf().xmap(...)` или храни в `CompoundTag` | | `Type inference failed` при `Image.userData.copy()` | Kotlin не выводит тип | Явно указывай: `val tag: CompoundTag = ...` | | `Too many arguments for matchPattern` | 3-й аргумент удален в 1.21.1 | `matchPattern(pattern, env)` вместо `(pattern, env, false)` | | `Overload resolution ambiguity` в `DeferredRegister.register` | Kotlin путает Supplier и Function | Оборачивай в `Supplier { ... }` | | `withStyle { style -> ... }` не работает | Component.withStyle не принимает лямбду | `Style.EMPTY.withColor(color)` | | `setCollarColor` is private (Cat/Wolf) | Метод стал приватным | Используй Java Reflection | ## 📋 ШАБЛОН ДЕЙСТВИЙ ПРИ КОНВЕРТАЦИИ ФАЙЛА 1. **Замени импорты** Yarn → Mojang (см. таблицу выше) 2. **NBT → Data Components**: `stack.nbt` → `stack.get(DataComponents.CUSTOM_DATA)` 3. **Networking**: Fabric packets → `CustomPacketPayload` + `PacketDistributor` 4. **Events**: `XxxCallback.EVENT.register` → `NeoForge.EVENT_BUS.addListener<XxxEvent>` 5. **Codec**: Добавь `HolderLookup.Provider` в методы сериализации Iota 6. **Методы сущностей**: `setX/Y/Z`, `position()`, `teleportTo()` 7. **Блоки**: `setBlockState` → `setBlock`, `isReplaceable` → `canBeReplaced()`, `isSideSolidFullSquare` → `isFaceSturdy` ## 💡 СТИЛЬ ОТВЕТА -
